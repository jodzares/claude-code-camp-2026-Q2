# Study Notes

These are my **personal learning notes** — one file per lesson, in my own words,
driven by my own comprehension as I work through the bootcamp.

**They are NOT the graded technical documentation.** The graded weekly journals
live in `docs/journal/`. A grader auditing this repo should look there, not here.

These notes exist only to help me learn and to let me revisit the reasoning behind
each design decision later. They mirror the Iterations study style (per-box "why it
exists," named patterns, delete-tests, an assembled diagram + boot story + spine
sentence) but are structured around whatever I personally found tricky — not around
any official checklist.
